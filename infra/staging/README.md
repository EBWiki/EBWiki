# Staging host OpenTofu (`staging.ebwiki.org`)

OpenTofu stack for staging on Railway: **`staging.ebwiki.org`**, runtime **`DOPPLER_TOKEN`**, and **`HOST`** in Doppler **`stg`** matching **`staging_hostname`**. The **`staging.ebwiki.org`** Railway custom domain is **imported** (already on the **ebwiki** service); apply does not create it again. OpenTofu sets **`target_port = 8080`** on that domain so traffic reaches Puma after import (Railway may clear the port when the domain is adopted).

Run **`make plan`** and **`make apply`** from a machine with Doppler **`ebwiki/infra`**. **`scripts/staging-plan.sh`** and **`scripts/staging-apply.sh`** load **`ebwiki/infra`** via **`doppler run`**. Bootstrap must have run first; see **`infra/bootstrap/README.md`**.

**Railway split:** **`.railway/railway.ts`** owns GitHub source (**EBWiki/EBWiki**, **main**), Dockerfile builder, **`RAILWAY_DOCKERFILE_PATH`**, and deploy settings. OpenTofu owns **`us-west2`** replicas, **`staging.ebwiki.org`** DNS and Railway verify TXT, custom domain, and **`DOPPLER_TOKEN`**. **`railway_service`** ignores source fields so the workspace token never calls repo-connect. Railway config runs first on apply; OpenTofu may **destroy** only **`cloudflare_ruleset.legacy_staging_redirect`** (the old redirect to grandkru). Install the Railway CLI and run **`npm ci`** once at the repo root.

**Rollback note:** After Railway config apply, **main** is the deploy branch and pushes to **main** can deploy staging. Revert deploy settings with a saved Railway config plan or dashboard history.

## Prerequisites in ebwiki/infra

After bootstrap, **`infra`** holds **`CLOUDFLARE_DNS_API_TOKEN`**, **`RAILWAY_TOKEN`**, **`DOPPLER_TOKEN`** for apply, **`STAGING_RUNTIME_DOPPLER_TOKEN`**, passphrases, **`STAGING_BASIC_AUTH_USERNAME`**, and Postgres DB name seeds.

**`terraform.tfvars`** is generated by **`scripts/write-staging-tfvars.sh`** before plan/apply.

## Cloudflare

Staging uses minted **`CLOUDFLARE_DNS_API_TOKEN`** on **ebwiki.org** only (staging CNAME + Railway verify TXT).
