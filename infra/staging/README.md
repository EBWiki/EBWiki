# Staging host OpenTofu (`ebwiki.staging.grandkru.com`)

OpenTofu stack for [GKT-462](https://linear.app/gkt/issue/GKT-462). Adopts the existing Railway **ebwiki** project and service, points **`ebwiki.staging.grandkru.com`** at Railway (Grand Kru standard: `<site>.staging.grandkru.com`), and wires runtime **`DOPPLER_TOKEN`** on Railway. **`HOST`** in Doppler **`stg`** matches **`staging_hostname`**.

**Legacy URL:** **`staging.ebwiki.org`** stays a proxied CNAME to the suspended Render origin (content not changed by OpenTofu). A Cloudflare **Single Redirect** ruleset sends **`staging.ebwiki.org`** to **`https://ebwiki.staging.grandkru.com`** with path and query preserved. Rollback: disable or remove the ruleset to stop redirects; the Render CNAME remains for emergency revert.

**Prerequisite:** **`make bootstrap`** so **`ebwiki/infra`** holds R2 credentials, **ebwiki.org** and **grandkru.com** DNS tokens, passphrases, **`RAILWAY_TOKEN`**, and apply **`DOPPLER_TOKEN`**. PR Manager runs bootstrap, plan, and apply from the PR Manager machine.

**Follow-up:** PR #4528 **`/health`** Access lock must include **`ebwiki.staging.grandkru.com`** (separate **`infra/cloudflare/`** stack after staging apply).

## Manual, no API

1. **Railway GitHub app:** browser install if needed; else PR Manager runs **`scripts/railway-github-access.sh`**.
2. **Railway CLI** on the PR Manager machine, plus an **SSH key registered** with Railway (`railway ssh keys add`) for Postgres snapshots via **`railway ssh`**.

Bootstrap seeds **`RAILWAY_TOKEN`**, **`TF_VAR_staging_basic_auth_username`**, and **`STAGING_EXPECTED_POSTGRES_DB`**. OpenTofu creates **`STAGING_PASSWORD`** in **`stg`** at apply time.

**`terraform.tfvars`** is generated by **`scripts/write-staging-tfvars.sh`** (Railway GraphQL plus Cloudflare lookups using **`ebwiki/infra`** tokens and zone IDs).

## Cloudflare providers

| Alias | Token in **`infra`** | Zone |
| --- | --- | --- |
| **`cloudflare.ebwiki`** | **`TF_VAR_cloudflare_dns_api_token`** | **ebwiki.org** (legacy record + redirect) |
| **`cloudflare.grandkru`** | **`TF_VAR_cloudflare_grandkru_dns_api_token`** | **grandkru.com** (staging CNAME + Railway verify TXT) |

Both tokens are minted at bootstrap from **`CLOUDFLARE_TOKEN_MAKER`**.

## Behavior change

Live staging runs image **`ebwiki/ebwiki:184`** with **`db:prepare`**. Apply switches to **main** with **`railway.staging.toml`**. Snapshots and apply: **`scripts/staging-apply.sh`**.

## Commands

```bash
make plan
make snapshot
make apply
```

Plan and apply run on the PR Manager machine via Doppler **`ebwiki/infra`** (not in PR CI).
